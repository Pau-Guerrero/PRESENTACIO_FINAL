## 5. Metodologia de treball

### Divisió de tasques
Jo m’organitzo segons l’assignatura. Quan toca una assignatura, treballo directament en aquella i avanço les seves tasques. Si ja he acabat el que tocava, aprofito aquella hora per avançar o acabar altres feines de la mateixa assignatura.  

No utilitzo cap eina externa de planificació perquè ja em sé organitzar bé pel meu compte. Si alguna vegada no arribo a temps o se m’oblida alguna cosa, m’ho apunto als recordatoris del mòbil.

### Ús de GitHub
Treballo directament des de Visual Studio Code connectat amb GitHub. Faig tota la feina des d’allà i després pujo els canvis al repositori.  

Per pujar els fitxers utilitzo comandes bàsiques de Git, que són les següents:
```bash
git add .
git commit -m "Conclusions Tasca03"
git push
````

### Kanban / organització

No utilitzo eines com Kanban o Trello. La meva organització es basa en seguir el ritme de les classes i completar les tasques dins del temps de cada assignatura.

Tot i així, mantinc un ordre clar en les meves carpetes i repositoris per saber en quin punt està cada feina.

### Seguiment del projecte

El seguiment el faig a través del meu propi treball i dels commits a GitHub, que permeten veure l’evolució del projecte.

Cada tasca està organitzada en carpetes separades, amb una estructura clara:

```bash
T03/
 ├── img/
 ├── solucio.md
 └── README.md
```


Això em permet tenir cada projecte ben estructurat i fàcil de revisar.
