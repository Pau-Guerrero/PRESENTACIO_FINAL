# 4. Organització

### Divisió de tasques
Jo m’organitzo segons l’assignatura. Quan toca una assignatura, treballo directament en aquella i avanço les seves tasques. Si ja he acabat el que tocava, aprofito aquella hora per avançar o acabar altres feines de la mateixa assignatura.  

No utilitzo cap eina externa de planificació perquè ja em sé organitzar bé pel meu compte. Si alguna vegada no arribo a temps o se m’oblida alguna cosa, m’ho apunto als recordatoris del mòbil.

### Ús de GitHub
Treballo directament des de Visual Studio Code connectat amb GitHub. Faig tota la feina des d’allà i després pujo els canvis al repositori.  

Per pujar els fitxers utilitzo comandes bàsiques de Git, que són les següents:
```bash
git add .
git commit -m "Conclusions Tasca03"
git push
```

### Kanban / organització

No utilitzo eines com Kanban o Trello. La meva organització es basa en seguir el ritme de les classes i completar les tasques dins del temps de cada assignatura.

Tot i així, mantinc un ordre clar en les meves carpetes i repositoris per saber en quin punt està cada feina.

### Seguiment del projecte

El seguiment el faig a través del meu propi treball i dels commits a GitHub, que permeten veure l’evolució del projecte.

Cada tasca està organitzada en carpetes separades, amb una estructura clara:

```bash
T03/
 ├── img/
 ├── solucio.md
 └── README.md
```

# 5. Problemes i aprenentatge

### Dificultats trobades
Al principi vaig tenir bastants complicacions, sobretot amb GitHub, ja que era nou per a mi. No entenia gaire bé com funcionava i em liava molt.  

També tenia molts errors a l’hora d’entregar les tasques i no sabia ben bé com gestionar-les correctament.  

Més endavant, quan vaig començar a utilitzar Visual Studio Code connectat amb GitHub, també em va costar bastant. No entenia com clonar repositoris, a vegades em sortien repositoris duplicats i tenia problemes per configurar el meu usuari i correu, cosa que feia que tot em donés errors.  

A més, al principi també tenia problemes amb els commits, ja que en pujar els canvis des de Visual Studio Code sovint fallava.

### Solucions aplicades
Amb el temps, practicant i fent servir GitHub de forma constant, em vaig anar acostumant al seu funcionament.  

Vaig solucionar molts dels problemes aprenent a utilitzar la terminal per fer els commits i pujar els canvis, cosa que em va donar més control i em va evitar errors.  

També vaig aprendre a clonar correctament els repositoris i a configurar bé el meu usuari i correu electrònic.  

### Què he après
Gràcies a aquesta experiència he après a utilitzar GitHub de manera correcta i a treballar amb repositoris sense errors.  

També he après a utilitzar Visual Studio Code de forma més eficient i a integrar-lo amb GitHub.  

A partir del projecte 6 ja em vaig acostumar completament a treballar així, i actualment puc treballar sense problemes i gestionar els meus projectes de forma ordenada i segura.
