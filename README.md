# 📘 README — Defensa Final del Projecte

## 🎯 Objectiu de la prova

Aquesta prova consisteix en una **defensa individual davant d’un tribunal de professors**.

No es tracta només de mostrar el resultat final, sinó de demostrar:

* Que entenc el que he fet.
* Que sé justificar les decisions preses.
* Que conec el meu repositori de GitHub.
* Que soc capaç d’analitzar problemes, riscos i solucions.
* Que puc comunicar informació tècnica de manera clara i estructurada.

⏱️ **Durada aproximada:** 15–20 minuts

***

## 🧭 Estructura de la defensa

La presentació es farà directament sobre el repositori GitHub, sense necessitat de diapositives externes.

### 📂 1. Preparació prèvia (obligatòria)

Cal crear un fitxer anomenat:

```
presentacio.md
```

Aquest document servirà com a guia de la defensa i haurà d’incloure:

* Presentació personal breu
* Índex de la defensa
* Enllaços als repositoris GitHub
* Documentació rellevant
* Captures o referències importants
* Explicació resumida dels projectes
* Conclusions i aprenentatges

👉 Es recomana una estructura clara, visual i fàcil de navegar.

***

## 🧩 Desenvolupament de la defensa

### 🔹 Part 1 — Presentació del GitHub

Cal explicar:

* El README inicial personalitzat
* L’estructura general del perfil
* Els repositoris principals del curs
* L’organització del treball (carpetes i estructura)

✅ Es valorarà:

* Ordre
* Claredat
* Bona documentació
* Qualitat dels commits
* Fluïdesa navegant pel repositori

***

### 🔹 Part 2 — Anàlisi de projectes

El tribunal seleccionarà **2 projectes aleatoris**.

Caldrà:

* Navegar pel repositori
* Explicar l’estructura
* Descriure les tasques realitzades
* Mostrar documentació
* Justificar decisions tècniques
* Analitzar problemes i solucions
* Explicar el procés seguit

🎯 No es tracta de memoritzar, sinó de demostrar comprensió.

***

### 🔹 Part 3 — Defensa tècnica

Es podran revisar projectes com:

* Projecte 01: Arranquem
* Projecte 02: Consultoria EverPia
* Projecte 03: Consultoria EverPia 2
* Projecte 04: Consultoria EverPia 3
* Projecte 05: La incubadora
* Projecte 06: Nexus
* Projecte 07: Food Logístics S.A.
* Projecte 08: Connecta’t al Futur

Caldrà explicar:

* El problema inicial
* La solució proposada
* Els passos seguits
* Les evidències generades
* Les decisions tècniques
* Les dificultats i com es van resoldre
* Els aprenentatges obtinguts

***

### 🔹 Part 4 — Metodologia de treball (OBLIGATORI)

Cal demostrar coneixement real de:

* Gestió de tasques
* Fases del projecte (anàlisi, planificació, desenvolupament, proves, documentació i entrega)
* Kanban (pendent, en curs, revisió, finalitzat)
* Diagrama de Gantt
* Gestió amb GitHub (commits, branques, issues, README, etc.)

📊 També s’ha de mostrar **una evidència real**, com per exemple:

* Tauler Kanban
* Gantt
* Issues
* Commits
* Documents del projecte

📌 Explicar un cas real, com:

* Una tasca que es complica
* Un problema tècnic
* Una reorganització del treball
* Una desviació de planificació

***

## 🔁 Recuperació de RA’s pendents

Si hi ha RA’s pendents:

* Crear un espai específic al repositori
* Organitzar-lo correctament
* Incloure evidències i documentació
* Preparar la seva explicació durant la defensa

✅ Es valorarà:

* Organització
* Documentació
* Qualitat de les evidències
* Capacitat de defensa tècnica

***

## 💡 Consells finals

* Practicar la presentació
* Preparar exemples reals
* Dominar el repositori
